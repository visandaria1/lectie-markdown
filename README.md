# lectie-markdown
1. Ce este un depozit și ce conține în plus față de un folder obișnuit?
Un depozit este un spațiu în care păstrăm fișierele unui proiect. În plus față de un folder obișnuit, acesta păstrează istoricul modificărilor prin commit-uri.
2. Ce este un commit? Ce informații înregistrează?
Un commit este o înregistrare a modificărilor făcute în depozit. Acesta conține autorul, data, mesajul și modificările salvate.
3. Care sunt regulile GitHub pentru parolă și numele de utilizator?
Parola trebuie să respecte cerințele de securitate GitHub. Numele de utilizator poate conține litere, cifre și cratime, nu poate conține spații sau caracterul _ și nu poate începe sau termina cu o cratimă. 

GitHub Docs



4. Care nume de utilizator sunt acceptate?
- ana-ionescu – acceptat, deoarece conține litere și o cratimă între cuvinte.
- -ana- – neacceptat, deoarece începe și se termină cu o cratimă.
- ana ionescu – neacceptat, deoarece conține un spațiu.
- ana_ionescu – neacceptat, deoarece conține caracterul _.
5. Ce se face pe calculatorul din laborator la sfârșitul orei și de ce?
Mă deconectez de la contul GitHub și șterg fișierele personale descărcate pe calculator, pentru a-mi proteja contul și datele.
6. Prin ce diferă un depozit Public de unul Private? Care se alege pentru portofoliu?
Un depozit Public poate fi văzut de oricine, iar unul Private poate fi accesat doar de persoanele autorizate. Pentru portofoliu aleg Public, ca profesorul să poată vedea lucrările.

9. Afișul a fost corectat. Cum se încarcă varianta nouă și ce se întâmplă cu cea veche?
Încarc varianta nouă cu același nume și salvez modificarea printr-un commit. Varianta nouă o înlocuiește pe cea veche în versiunea actuală, dar cea veche rămâne în istoricul modificărilor.

12. Care sunt pașii de activare GitHub Pages? Ce fișier este prima pagină?
1. Intru în depozit și apăs Settings.
2. Aleg Pages.
3. La Build and deployment, selectez Deploy from a branch.
4. Aleg ramura main și folderul / (root).
5. Apăs Save.
Prima pagină poate fi index.html, index.md sau README.md, în funcție de configurație.

14. Trei lucruri care nu se publică într-un depozit public.
